# Aggregate results

`published_matched_summary.csv` contains 60 selected aggregate rows from the
study's supplementary configuration table: 20 source learners and three
calibrators on the same two assays selected by the simple–convex minimax design.
Uptake RMSE is in mg/g; log RMSE uses the natural logarithm. Each configuration
is evaluated on the same 2,070 repeated query exposures, across 16 material
labels and five fixed splits. These rows are not new experiments or individual
experimental records. The plotting example changes presentation, not results.
